# 橋頭森林守護者：城市的抉擇

地理版 2.3 · 2026.11.23

[進入遊戲](https://maskywg.github.io/qiaotou-forest-guardians-game-20261123/)

以橋頭糖廠森林、既有市鎮、台 1 線與捷運為背景的繁體中文 3D 規劃遊戲。本 repo 是遊戲獨立公開版。

- 旋轉、平移、縮放立體場景，分層查看既有市鎮、舊省道、捷運與臺鐵。
- 畫道路，配置住宅、綠廊及滯洪地，在 600 點預算內兼顧各項需求。
- 可點選森林阿嬤、生態動物與圖鑑，並切換日夜。
- 三種虛構城市壓力事件，選項效果透明。
- 暴雨測試、復原、本機存讀檔與十年後成果。
- 操作旁的 i 說明採側欄；手機另分配說明空間，保持地圖可見。

## 本機執行

在此資料夾執行 `python3 -m http.server 8765`，開啟 http://localhost:8765/。
程式與 Three.js 已隨檔提供，無需安裝依賴或設定 API 金鑰。

## 資料與示意限制

街道、地物輪廓及捷運站座標來自 OpenStreetMap；詳見 [OPEN-DATA.md](OPEN-DATA.md)。建物高度、部分街廓量體、樹木、動物及站體為示意。模型沒有實測高程、交通量或排水網，遊戲分數與逕流指數不能作為工程或淹水預測。阿嬤卡通造型與台詞為創作；城市壓力事件不指涉特定企業或人物。

方案與動物觀察筆記只儲存在使用者的瀏覽器，不提供跨裝置同步。從舊私人網址儲存的方案不會自動轉移到新網址。
