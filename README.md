# 橋頭森林守護者：城市的抉擇

地理版 2.3 · 2026.11.23

[進入遊戲](https://maskywg.github.io/qiaotou-forest-guardians-game-20261123/)

以橋頭糖廠森林、既有市鎮、台 1 線與捷運為背景的繁體中文 3D 規劃遊戲。本 repo 是遊戲獨立公開版。

- 旋轉、平移、縮放立體場景，分層查看既有市鎮、舊省道、捷運與臺鐵。
- 畫道路，配置住宅、綠廊及滯洪地，在 600 點預算內兼顧各項需求。
- 可點選森林阿嬤、生態動物與圖鑑，並切換日夜。
- 三種虛構城市壓力事件，選項效果透明。
- 暴雨測試、復原、本機存讀檔與十年後成果。
- 操作旁的 i 說明採側欄；手機另分配說明空間，保持地圖可見。

## 本機執行

在此資料夾執行 `python3 -m http.server 8765`，開啟 http://localhost:8765/。
程式與 Three.js 已隨檔提供，無需安裝依賴或設定 API 金鑰。

## 資料與示意限制

街道、地物輪廓及捷運站座標來自 OpenStreetMap；詳見 [OPEN-DATA.md](OPEN-DATA.md)。建物高度、部分街廓量體、樹木、動物及站體為示意。模型沒有實測高程、交通量或排水網，遊戲分數與逕流指數不能作為工程或淹水預測。阿嬤卡通造型與台詞為創作；城市壓力事件不指涉特定企業或人物。

方案與動物觀察筆記只儲存在使用者的瀏覽器，不提供跨裝置同步。從舊私人網址儲存的方案不會自動轉移到新網址。

Three.js 0.160.1 使用 MIT 授權，見 vendor/THREE-LICENSE.txt。

## 清晰地圖版 2.4 · 2026.11.23

- 地圖、上方指令列、下方建設列、狀態列使用各自的 Grid 版面空間；操作按鈕不再定位在地圖上。短視窗以橫向捲動操作列容納項目。
- 預設關閉地標與動物浮動標記；需要時可打開。圖鑑尋找會拉近角色並顯示標記，回到全景後再關閉。
- 解說與對話：桌面使用側欄；手機在下方分配獨立空間，短視窗會暫收操作列，地圖與說明不重疊。
- 加入地圖外的快速降雨開關及 20／80／150 mm/h 情境選單。
- 加入河川外溢教學示意。假設抬升值 R=max(0,(雨量−50)/100×2.5−滯洪地格數×0.08−綠廊格數×0.006)，外溢影響距離為 2.5R；依格點至溪流的距離示意沿岸影響。這個門檻與量級都是遊戲假設，沒有實測高程、堤防高度、上游流量或排水資料，不能當作真實淹水預報。
- 驗證：1280×800、640×400、390×844 操作不與地圖重疊；住宅配置與預算、復原仍可使用。空白配置下 20 mm/h 外溢示意 0 格，150 mm/h 為 114 格。

## 雙鐵列車版 2.5 · 2026.11.23

- 新增四節藍白塗裝臺鐵列車，車窗、車頭、車底與車頂設備為遊戲造型；沿既有臺鐵折線逐節行駛，往返運行。
- 「看臺鐵」可拉近並跟隨列車，支援停止跟看與回到全景。臺鐵圖層一併控制軌道及列車顯示。
- 頁首新增「森林主網頁」按鈕，另開 https://maskywg.github.io/qiaotou-forest/ 。
- 列車車型造型、車速與往返時間均為示意，非真實車型重建或班表。
- 驗證四節車廂在正反向時間取樣皆落在原始臺鐵線形上，追蹤視角、圖層切換與返回全景可用。
